# Recorded examples

All organizations and source material here are synthetic. No real prospects, donor data, or live articles are included.

| Directory | Execution basis | Meaning |
| --- | --- | --- |
| `fixture-replay` | `synthetic_fixture` | Hand-authored researcher, skeptic, and fact-checker examples replayed through the code. Research intentionally includes planted errors. Matching the known answers demonstrates plumbing and validator behavior, not model accuracy. |
| `session` | `model_checked` | Source-specific outputs authored during the current Codex coding session. The same assistant performed all roles in one shared session context and had access to the fixture expectations. This is an open-book demonstration, not a blind evaluation or independent review. |

Each directory retains collection counts, the actual versioned input/output of each stage, and the rendered report. Source-faithfulness, independent corroboration, and commercial relevance remain distinct. No owner usefulness review or real-source accuracy measurement has occurred.

Session artifacts are records of actual outputs, not automatically generated by `scripts/demo.py`. Fixture replay is reproducible without network access or model calls. A future coding environment can read these contracts and evidence, submit new outputs through the CLI, and compare results without a provider migration.
