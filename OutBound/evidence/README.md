# Evidence

This directory contains preserved run-specific inputs, assessments, outputs, and reproduction instructions.

- [Day 2 incremental collection](day-2/first-run.md) records first-run results. [Reproduction and provenance](day-2/README.md) distinguish the Seattle pilot from the incremental baseline.
- `live_runs/` contains bounded live-source sessions.
- `evaluations/` contains workflow evaluation sessions.

These artifacts establish what a particular run did. They do not establish source completeness, independent verification, or unattended operation.
