# OutBound

This directory contains Tributary's operating system for nonprofit account discovery and signal generation. Code remains in `tributary/`; tests remain in `tests/`.

| Directory | Purpose |
| --- | --- |
| `frameworks/` | Product requirements, project plan, workflow, and system specifications. |
| `research/` | External evidence reviews, source research, feasibility work, and research limitations. |
| `evidence/` | Preserved bounded live runs and evaluation sessions. |
| `tracker/` | Roadmap and owner feedback tied to implementation status. |
| `data/` | Test and operating data that are safe to commit. |
| `archive/` | Superseded or historical implementation records retained for traceability. |

Reviewable spreadsheets, documents, and PDFs belong in `Library/`, not here. Private pursuit decisions and outreach messages are outside this public repository.
